Разработано на Django Rest Framework 
Проект заготовка для читалки комиксов.

Реализована основная часть серверного функционала. 
А именно:
* Логин и Регистрация с JWT
* Личный кабинет(профиль)
* Каталог комиксов
* Просмотр и чтение 
* Модерация + добавление новых комиксов
* Поиск и сложные Q-фильтрации 
* Система рейтингов и популярности
* Отзывы
* Комментарии 
* Заготовка под подключение к S3

• REST API
• Реализовал сложные фильтрации и оптимизацию ORM-запроcов
• Интегрировал Google OAuth.
